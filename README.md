# AntSim - Colony Simulator

Simulador de ecossistema de colônia de formigas construído em Python com Pygame.
Projeto focado em comportamento emergente e sistemas de IA.

## Como rodar

pip install pygame
python main.py

## Tecnologias

- Python
- Pygame
